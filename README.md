# FixCampus
Sistem Informasi Pemeliharaan Fasilitas Kampus Berbasis Web (PHP 8, MySQLi, MariaDB, Bootstrap).

## Menjalankan di lokal
1. Salin folder ini ke `C:\xampp\htdocs\fixcampus`.
2. Jalankan Apache dan MySQL di XAMPP.
3. Impor `database/fixcampus.sql` lewat phpMyAdmin.
4. Buka http://localhost/fixcampus/test_koneksi.php (semua baris harus OK).
5. Akun contoh: dinda@fixcampus.test, rudi@fixcampus.test, andi@fixcampus.test (password: password123).
